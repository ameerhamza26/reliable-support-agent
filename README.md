# Reliable Support Agent

An educational AI support agent built with Python and Spring Boot.

The project explores tool calling, authorization, retrieval,
human approval, idempotency, and failure evaluation.

All customers and orders are fictional. Refunds are simulated.

## Learning roadmap

- [ ] 01: Secure order lookup API
- [ ] 02: Python agent with an order lookup tool
- [ ] 03: Retrieval from shop policies
- [ ] 04: Approval-controlled, idempotent refunds
- [ ] 05: Failure experiments and evaluations
- [ ] 06: Complete local demo

## Structure

- backend/: Spring Boot business API
- agent/: Python agent and tools
- knowledge/: Fictional shop policies
- evaluations/: Evaluation scenarios
- docs/lessons/: Implementation lessons
- docs/failure-cases/: Reproducible failure reports
